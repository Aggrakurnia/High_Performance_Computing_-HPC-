# High Performance Computing (HPC)

Repositori ini berisi materi, kode implementasi, dan analisis eksperimen untuk mata kuliah **High Performance Computing (HPC)**. Fokus utama dari repositori ini adalah mempelajari optimasi waktu eksekusi program menggunakan teknik pemrograman paralel (*multithreading*).

## 📌 Isu & Pembahasan Utama
- **Bottleneck Komputasi Sekuensial**: Menganalisis keterbatasan waktu dan kinerja saat algoritma dijalankan secara serial (1 *thread*).
- **Implementasi Pemrograman Paralel**: Menerapkan teknik *multithreading* untuk membagi beban kerja ke dalam beberapa *core* CPU secara bersamaan.
- **Pengukuran Performa (*Benchmarking*)**: Membandingkan waktu eksekusi (*execution time*) antara pendekatan sekuensial dan paralel.
- **Analisis Scalability & Speedup**: Mengukur efisiensi penambahan *thread* terhadap peningkatan kecepatan program serta mengidentifikasi titik jenuh performa.

## 📁 File Utama
- `High_Performance_Computing_(HPC)_(2).ipynb` : Jupyter Notebook yang memuat seluruh implementasi kode, skenario pengujian, dan visualisasi analisis performa.
